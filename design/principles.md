# Rivet visual direction

A calm hardware workbench: the model is the focal point, with clear evidence beside it. Preserve the existing dark surfaces, system typography and blue primary action. Color never replaces a status word. The product is a supported rover builder, not exact reconstruction of any uploaded product.

## Moodboard and identity (#35)

The original [visual sheet](moodboard.svg) combines layered graphite surfaces, blue selection, engineering monospace labels, and explicit pass/warning/unknown states. It contains original vector primitives and no third-party assets. Screenshots in `screenshots/` show the implemented studio at 1440, 1024, 768 and 390 pixels.

- Keep the canvas centered and visible within one viewport. Side panels scroll internally, including long findings and complete buy lists.
- Use one top-level mode navigation. Show contextual tools only where useful; move developer controls behind the existing developer flag.
- The landing page offers Upload an image and Describe a build. Intake reviews interpretation before confirming generation; saved examples remain a separate instant path.
- Put supplier identity and verification beside the selected part. Separate historical catalog values, current supplier checks, and geometry/fit evidence.
- Keep synthetic, fallback, unknown-price and blocking-check disclosures visible. Use plain language before technical details.
- Use 4px spacing increments, 12–15px panel text, rounded rectangular controls, visible focus rings, and reduced-motion preferences. Text/body contrast meets WCAG AA for documented token pairs.

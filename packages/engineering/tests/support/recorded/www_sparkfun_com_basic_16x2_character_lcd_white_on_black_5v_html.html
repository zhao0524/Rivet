Product Overview

This is a basic 16 character by 2 line display with a snazzy black background with white characters. Utilizes the extremely common HD44780 parallel interface chipset (datasheet). Interface code is freely available. You will need ~11 general I/O pins to interface to this LCD screen. Includes white LED backlight.

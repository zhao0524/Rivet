## 3. Architecture

- `packages/engineering/rivet_engine/design_ir/`: strict DesignSpec v2 (bodies, shapes, features, anchors, attachments, patches, digests, topology signature).
- `rivet_engine/geometry/`:
  - `parametric.py` and `features.py` on OCCT 7.9.3 (`cadquery-ocp-novtk`): B-rep solids and features.
  - `freeform.py`: occupancy blends meshed by vectorized marching tetrahedra; GLB/STL import.
  - `constraints.py`: anchor solver.
  - `collision.py`: AABB broadphase, manifold3d boolean narrowphase, `min_gap` clearance, joint sweeps, access rays.
  - `stability.py`, `manufacturing.py`, `repair.py`.
  - `catalog_geometry.py`: exact catalog-ID recipes, labelled `procedural_approximation`.
  - `meshing.py`: deterministic GLB/STL, digests.
  - `exports.py`.
- `rivet_engine/design_compiler.py`: `compile_design(spec, catalog, output_dir=..., seed=..., progress=...)`. `rivet_engine/engineering_bridge.py`: engine-authoritative electrical/firmware, with separate claim statuses.
- `services/api/rivet_api/design/`:
  - `providers.py`: OpenAI chat/vision and image ports, call ledger.
  - `procedural.py`: offline author, always labelled `fixture`.
  - `render.py`: six-camera CPU rasterizer; Chromium optional.
  - `critic.py`, `orchestrator.py`: state machine, cache/replay, revisions.
  - `artifacts.py`: SQLite jobs/events/revisions, content-addressed assets.
  - `setup.py`.
  - `routes/design_v2.py`.
- `apps/web`:
  - `components/three/generation/*`: GeneratedAssembly, PreviewSwapper, CandidateCompare, VisualDiff, DesignLayers, EditableFeatureHandles.
  - `components/studio/generation/*`: DesignStudio, GenerationTimeline, DesignChoice, useDesignJob.
  - Intake button "Generate 3D design (3 candidates)" (API mode).
- Contracts: `contracts/design-spec.v2`, `design-bundle.v2`, `geometry-preview-event.v2`, `visual-review.v2`, `fabricated-part.v2` (generated by `scripts/export_design_schemas.py`, checked in CI). The v1 BuildPlan is untouched; engineered bundles link the engine's v1 plan.
- Fixtures: `fixtures/design/` (2WD, 4WD, robot arm, angled sensor housing, hummingbird).

## 4. Run instructions

- Install: `cd packages/engineering && uv sync --extra dev`; API venv: `uv venv services/api/.venv --python 3.11 && uv pip install --python services/api/.venv/bin/python -e 'services/api[dev,live]' -e 'packages/engineering[geometry]'`.
- Offline (default): `RIVET_3D_MODE` unset, then `pnpm dev`. The web app must use the API (`NEXT_PUBLIC_RIVET_USE_FIXTURES=false`) for the v2 button.
- Live: `RIVET_3D_MODE=live`, `OPENAI_API_KEY`, optional `RIVET_DESIGN_MODEL`, `RIVET_IMAGE_PROVIDER=openai`, `RIVET_IMAGE_MODEL`, `RIVET_IMAGE_SIZE`, `RIVET_IMAGE_QUALITY`, `RIVET_RENDERER`.
- Live smoke: `services/api/.venv/bin/python scripts/live_design_smoke.py "<prompt>" [--images] [--mode engineered]`.

## 7. Defects and blockers

- **Live image generation (A3/A4) is blocked.** The configured key returns `400 The model 'gpt-image-1' does not exist`. The model is configurable (`RIVET_IMAGE_MODEL`); the job failed visibly with no fixture substituted.
- **Live-authored designs are simple** (3–4 bodies) and failed stability. The authoring prompt needs examples, and model-guided repair (C5) has not yet produced a recorded fix.
- **Offline authoring is rule-based:** archetype templates parameterised by the request and image measurements. It is labelled `fixture` everywhere.
- **Open-face shells on fully filleted solids** use a fallback that can leave a small lip (reported by checks, not hidden).
- **Restarts:** interrupted jobs are marked failed after a restart, not resumed.
- **Viewer overlays missing:** no joint, mount or collision overlays yet.
- **Purchased-part fit:** mounting fit is reported UNKNOWN; no licensed manufacturer CAD is bundled.
- **Kernel lock:** geometry compiles are serialized by a process lock for OCCT safety. Candidate authoring still runs concurrently.
- **No blinded A/B benchmark** has been run.
- **Leftover environment:** `.venv-runtime` from the earlier session has mixed OCP builds; it is unused and was left in place.

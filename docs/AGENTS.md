# Agent instructions

Everyone working in this repo must follow these rules:

1. Before starting any task, read [`context.md`](context.md), then [`docs/agent-collaboration.md`](docs/agent-collaboration.md), then `docs/implementation.md` sections 0–5 and your lane in section 6.
2. When you finish a task, update `context.md`: task board status, *Done* entry, work log line.
3. Before every `git push`, make sure `context.md` reflects the code being pushed.
4. Only edit files in your lane's folders (see `context.md` section 2).
5. Commit messages and PR titles/descriptions must not mention AI: no AI `Co-Authored-By` trailers, no "Generated with ..." lines, no tool or model names.
